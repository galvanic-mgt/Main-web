# Galvanic Website

Static portfolio website for Galvanic, a Hong Kong marketing agency working across interactive games, mall decor, pop-ups, roadshows, exhibitions, and event operations.

## Local Preview

Run a local server from this folder:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4173
```
